FORM — TRAINING TRACKER
=======================

WHAT'S INCLUDED
- index.html: mobile-responsive workout tracker, no server or API required.
- manifest.webmanifest, icon assets, sw.js: installable web app when hosted over HTTPS.
- Start date: Sunday, October 25, 2026. First Just Run session pre-recorded as complete.

GET STARTED
1. Double-click index.html to open in a desktop browser, or host the entire folder with GitHub Pages, Netlify Drop, or another static host.
2. On iPhone, open the hosted HTTPS URL in Safari; choose Share -> Add to Home Screen.
3. Select a day, enter reps/weight and effort, and choose Finish workout.
4. In Settings, Export my data regularly. The browser stores logs locally and does NOT sync between your iPhone and Mac automatically. Import the backup on your other device as needed.

WEIGHT SUGGESTIONS
- First time: the app displays very light trial weights in pounds; these are examples to calibrate, not individually tested working weights. Adjust down when needed or change in the exercise card. Machine markings vary significantly.
- After logging: the app uses the last completed session for that exercise. If all sets hit the top of the target range with comfortable technique, it suggests one machine increment more. If too hard or below the rep range, it suggests one step less. Otherwise it holds.
- Changes should be made only with good form, and discontinue a movement that causes pain. Seek medical clearance before training given surgery and health history.

FORM TUTORIAL SOURCES
All tutorials are by PureGym. Where no verified direct YouTube video was found for the exact lift, the app clearly labels an alternate-machine video or offers PureGym's written guide plus a YouTube search.
